WHOIZ PRODUCTIONS WEBSITE

1. Open index.html to preview the site.
2. Add your background video to this folder and name it: hero.mp4
3. The signup form is configured for Whois.prod@gmail.com using FormSubmit.
4. IMPORTANT: FormSubmit normally sends a one-time activation email the first time the form is submitted. Confirm it from Whois.prod@gmail.com before expecting live submissions.
5. You can edit wording, links, roles, and sections in index.html.
6. This folder can be published free on GitHub Pages or Cloudflare Pages.
